# BioLogix

AI-powered biometric attendance tracking system featuring real-time facial recognition, geolocation tagging, encrypted biometric templates, and offline check-in caching.

## Tech Stack

- **Client:** React, Vite, TypeScript, Tailwind CSS
- **Server:** Node.js, Express, TypeScript, PostgreSQL, Prisma
- **AI Service:** Python, Flask, OpenCV, TensorFlow / DeepFace
